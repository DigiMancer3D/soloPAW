## Button : action ratio

Using the strict 87-row basis:

- **11 physical button-like controls** — LMB, RMB, Wheel Click, G4–G9, Left Tilt, Right Tilt — provide access to **65 binding-row actions**: **11:65 = 1:5.91**.
- If **Wheel Up and Wheel Down are also treated as two independent physical control inputs**, the effective ratio is **13:65 = 1:5.00**.
- Previous v2.3 on the same strict basis was **11:61 = 1:5.55**, or **13:61 = 1:4.69** including Wheel Up/Down as independent inputs.
- This is a **+6.6% increase in strict covered binding rows** from v2.3 to v2.5: 61 → 65.

The earlier approximate “~63–65 practical actions” estimate mixed screenshot rows with contextual extras. The numbers above intentionally use one consistent denominator, the 87 reviewed binding rows, so v2.3 and v2.5 are directly comparable.

- The action-bearing controls collectively occupy **34 active button/category pairs**, giving an overall density of **65 / 34 = 1.91 binding-row actions per active button-state category**.

### Architectural improvement from v2.3

The increase is not just raw density. v2.5 moved more useful work onto deliberate normal tap/double/hold gestures while reducing disruptive G-Shift outputs:

- v2.3: **32 normal/non-shift strict rows + 29 G-Shift rows = 61**
- v2.5: **37 normal/non-shift strict rows + 28 G-Shift rows = 65**

So v2.5 gains **5 normal-side rows**, deliberately drops **1 shifted disruptive row**, and still finishes **4 rows ahead overall**.

The native vertical wheel remains exactly as it was in v2.3, including unlocked/free-spin behavior.

# Megabonk — soloPAW direct-key profile

Current public profile: `soloPAW-Megabonk-v1.1-DirectKeys-Esc.json`

Megabonk validates the direct-key side of soloPAW: important controls are ordinary press/release mappings instead of timing macros.

| G502 control | Output / purpose |
|---|---|
| G4 | `S` — backward |
| G5 | `W` — forward |
| G6 | raw output disabled / chord modifier |
| G6 + G5 | `M` — hold map |
| G7 | Space — repeated jump presses |
| G8 | Left Ctrl — slide hold |
| Wheel Click | `F` — interact |
| G6 + Wheel Click | `Q` — aim toggle |
| Left Tilt | `A` |
| Right Tilt | `D` |
| G6 + Right Tilt | Esc |
| G9 | `T` — quick reset |
| LMB / RMB | native interaction |
| Wheel Up / Down | native |

This profile deliberately contains no `if_tap`, `hold_keys`, `wait`, or soloPAW state macros for the primary game controls.

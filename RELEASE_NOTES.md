# soloPAW v0.1.0-rc.1 — GitHub launch candidate

## One mouse, dense controls, less reach

This first combined soloPAW repository brings the project’s two Linux GUI tools and current public G502 profiles together under one source tree.

### Included

- **soloPAW Profile Switcher v0.2.1** — stream-safe Input Remapper switching, aliases, quick slots, autoload control, profile import/public-safe export, and service diagnostics.
- **soloPAW Controller Map Studio v0.1.0-rc.1** — WYSIWYG `.udata` control-map authoring, rendered PNGs, binding tables, Input Remapper export, and desktop integration.
- **Cyberpunk 2077 soloPAW v2.8** — current `JDirect-ScanH-QuickW` reference profile.
- **Megabonk soloPAW v1.1** — direct-key reference profile for ordinary press/release and sustained-hold behavior.

### Cyberpunk reference density

Using the project’s documented 87-row review method, the current arrangement reaches **66/87 reviewed rows (75.9%)**, while preserving native vertical wheel/free-spin behavior and keeping rollback profiles as separate versions.

### Public-release focus

- local-first Linux tooling;
- one-hand / mouse-first and reduced-reach workflows;
- stream-safe profile switching;
- public-safe Input Remapper profile export;
- explicit privacy checks before publication;
- no personal home paths or machine identifiers in public profile JSON.

### Release status

This is a **release candidate** for the combined GitHub repository. The Controller Map Studio remains RC1, and the repository intentionally leaves the project-wide software license undecided until the owner selects one.

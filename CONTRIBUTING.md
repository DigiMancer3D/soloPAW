# Contributing to soloPAW

Thanks for helping improve mouse-first and accessibility-oriented control mapping.

## Profile contributions

Include the mouse/device model, operating system, Input Remapper version, game/application, required in-game key changes, direct press/hold requirements, and what was tested in actual gameplay.

Do not include usernames, home paths, hostnames, raw keystroke logs, tokens, or unrelated configuration. Prefer the Profile Switcher's public-safe export function.

## Code contributions

Keep the project local-first and stream-safe. Preserve user profiles/data. Add focused tests for behavior changes and keep rollback possible.

## Accessibility

Avoid assuming one grip, reach pattern, timing window, or physical ability fits everyone. Explain the ergonomics a change supports rather than presenting it as universally better.

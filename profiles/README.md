# soloPAW Input Remapper profiles

These are public-safe reference profiles for the Logitech G502 HERO family and Input Remapper.

| Game | Current public profile | Style |
|---|---|---|
| Cyberpunk 2077 | `soloPAW-Cyberpunk2077-v2.8-JDirect-ScanH-QuickW.json` | Dense G-Shift + tap/double/hold layout |
| Megabonk | `soloPAW-Megabonk-v1.1-DirectKeys-Esc.json` | Direct-key / real press-hold oriented layout |

The files intentionally omit `origin_hash`, usernames, home paths, hostnames, and machine-specific logs.

These profiles assume the G502 emits the same Linux input button/key codes used during soloPAW development. Onboard mouse configuration can change those codes. Test manually before enabling autoload.

The Cyberpunk profile also depends on matching in-game key bindings. See [`docs/CYBERPUNK2077_PROFILE.md`](../docs/CYBERPUNK2077_PROFILE.md).
